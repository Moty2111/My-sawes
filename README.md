# 🛒 My-Sawes — Строительный магазин (Прототип)

Адаптивный прототип сайта для магазина строительных материалов и инструментов.
Разработан с упором на чистый код, современный дизайн и удобство использования на любых устройствах.

## ✨ Ключевые особенности

- 📱 **Полная адаптивность** — корректное отображение от смартфонов до десктопов.
- 🎨 **Строгая цветовая гамма** — контрастный черно-белый стиль с яркими оранжевыми акцентами.
- 🧩 **Чистая архитектура** — разделение структуры (HTML), стилей (CSS) и логики (JS).
- ⚡ **Интерактивные элементы** — бургер-меню, слайдеры и плавные переходы.
